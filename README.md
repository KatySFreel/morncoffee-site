# MORNCOFFEE

Адаптивная верстка полного макета Paper:
https://app.paper.design/file/01M32PX271RQFZ5WYA1S80K9G2/p-1-0/1-0

## Запуск

Из папки `morncoffee-site`: `python3 server.py` (Python 3.10+).

- Сайт: http://127.0.0.1:4175/
- Админка: http://127.0.0.1:4175/admin/

В админке можно добавлять, редактировать, удалять и переставлять товары, позиции меню и события. Выключите «Показывать на сайте», чтобы сохранить черновик. Фото — JPG, PNG, WebP или GIF до 8 МБ; также можно выбрать уже загруженное изображение. После сохранения обновите страницу сайта.

Каталог хранится в `data/content.json`, новые фотографии — в `assets/uploads/`. Перед сохранением автоматически создаётся копия предыдущего каталога в `.admin-backups/`. Кнопка «Скачать резервную копию» сохраняет JSON отдельно; фотографии нужно копировать вместе с папкой assets. Для восстановления остановите сервер, замените `data/content.json` нужной копией и запустите сервер снова.

Админка доступна только на этом компьютере: сервер слушает 127.0.0.1 и проверяет источник запросов. Это локальный редактор; для удалённого доступа понадобится отдельное размещение и авторизация. GitHub Pages показывает статический снимок каталога, но не поддерживает запись из админки. Локальные изменения автоматически в интернет не публикуются.

Проверки: `python3 -m unittest discover -s tests`.

HTML, CSS, JavaScript без сборки и внешних библиотек. Все изображения и шрифты локальные. Для сайта используются оптимизированные WebP; исходные PNG сохранены в assets.

Разделы: первый экран, Upcoming Events, Feel the Vibe, Menu, More Than a Coffee Shop, Merch, Community и подвал с контактами. Первый экран следует высоте окна, типографическая группа сохраняет компактные пропорции. Минимальная высота — 600 px на десктопе и 568 px на мобильном (увеличивается пропорционально ширине). Мобильная версия следует артборду LR-0: фото сверху, события и меню в горизонтальных галереях, мерч расположен каскадом.

Навигация ведет к разделам. В меню работают вкладки и управление стрелками клавиатуры. Мероприятия и товары открываются в попапах-пластинках по артбордам 12R-0 и 195-0. Диалоги закрываются кнопкой или Escape; у футболки работают переключатели размера и цвета. Форма проверяет формат email.

Год мероприятий не указан: календарь ожидает подтверждения даты. Регистрация, онлайн-покупки и подписка не подключены к серверу; интерфейс не сообщает об успешной отправке. В исходном макете нет содержимого Drinks/Food, адресов соцсетей и юридических документов: для них показаны состояния ожидания. Даты, цены (включая £2.80 для футболки) и тексты сохранены из макета. Некоторые векторные декорации и логотип воспроизведены упрощённо.

## Версии и публикация

Локальная итерация `version-2` сверяется с [макетом Figma](https://www.figma.com/design/hqsjZtXWCkIfBo5LwXVwiD/Coffee-Rave?node-id=637-31380).
Векторные стикеры, знак в шапке, центральный персонаж с линиями рук/ног и нижний логотип экспортированы из исходного макета в SVG. Зернистая текстура входит в оригинальный дизайн. Ноты первого экрана сохранены отдельным WebP с прозрачностью. Геометрические уточнения собраны в `refinements.css`.
По текущей договорённости правки версии 2 остаются локальными; публикация выполняется отдельно по просьбе пользователя.

Дополнительная сверка: ноты подняты над DJ; билеты получили фирменный штрихкод и прозрачную перфорацию. Галерея использует составные фотографии с иллюстрациями из Figma (экспорт 1.5–3×), две бесшовные ленты и кнопку паузы; при `prefers-reduced-motion` движение отключено. Подпись привязана к букве H. Персонажи мерча экспортированы с исходной ориентацией и пропорциями. Стили этой итерации — `gallery.css`.

- `main` — актуальная согласованная версия сайта, открывается по основному адресу.
- `version-1` — первая версия, отдельный адрес `/v1/`.
- Следующие итерации: `version-2`, `version-3` и т. д., адреса `/v2/`, `/v3/`.
- Метка `v1.0.0` сохраняет исходное состояние первой версии.

Новую итерацию начинаем отдельной веткой от последней версии. Предыдущие версии не перезаписываем. После доработки объединяем согласованные изменения с `main`. GitHub Actions публикует основную страницу и снимки всех веток `version-N`. Чтобы обновить только ссылку версии до объединения, запускаем workflow `Publish website and versions` вручную из `main`.

В Settings → Pages источником публикации должен быть GitHub Actions. В публичную сборку попадают только HTML, CSS, JavaScript и используемые форматы изображений/шрифтов; исходные PNG остаются в репозитории.

Сверка с обновлённым Paper 1CV-0: составные изображения напитков и нижний логотип с иллюстрациями сохранены в `assets/paper-*.webp`. Изображения меню уже содержат декор, поэтому отображаются без повторного увеличения старых фонов. Фигурные края карточек About, типографика и геометрия футера — `paper-update.css`. На мобильных экранах сохранён компактный SVG-логотип.

Футер уточнён по Paper 1Z9-0: размеры шрифтов, интервалы контактов и часов, оригинальный стикер Social media, Facebook/Instagram. Профили пока используют прежние информационные заглушки. `interactions.css` задаёт ховеры без подчёркивания, клавиатурный фокус, реакцию на нажатие, переходы вкладок и попапов. Карточки появляются однократно через IntersectionObserver; галерея ставится на паузу вне экрана и под попапом. Системный prefers-reduced-motion отключает движение.
